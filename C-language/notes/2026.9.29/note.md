**P8**笔记：
函数调用时，动态变量开辟空间；
函数调用结束后，动态变量释放空间。

```c
#include <stdio.h>
int main(){
    int max(int x,int y);
    ...
}
int max(int x,int y){
    ...
}
```
第一个`int max(int x,int y)`是对被调用函数max的声明，第二个是对max函数的定义。
要声明的原因：
因为在主函数中要调用max函数，而max函数的定义却在main函数之后，对程序的编译是自上而下进行的，在调用max时，编译系统无法知道max是什么，因而无法把它作为函数调用处理。为了使编译系统能识别max函数，就要在调用前进行声明。（P8）
