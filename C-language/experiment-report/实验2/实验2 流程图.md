## 1. 实验2-1 圆面积与周长流程图

```mermaid
flowchart TD

```

## 4. 实验2-4 反向译码流程图（含编码越界回绕）

```mermaid
flowchart TD
A([开始]) --> B["把 c、h、i、n、a 依次赋给 c1~c5"]
B --> C["n1~n5 分别等于 c1~c5 的编码减 4"]
C --> D{"编码小于等于 96 ？"}
D -- 是 --> E["编码加 26，回绕到 z 一侧"]
D -- 否 --> F[/用 %c 逐个输出 n1~n5/]
E --> F
F --> G([结束])
```

实验2-3 是阅读程序分析输出的实验，程序没有分支与循环，因此不画流程图，分析写进「实验结果与分析」即可。
