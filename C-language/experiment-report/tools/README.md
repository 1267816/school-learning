# 实验报告生成脚本

这个目录放的是 C 语言实验报告用的 Python 脚本，配套 `C-language/experiment-report/` 下的实验1～6。脚本只读写 docx，不直接产出 doc。

依赖：`pip install python-docx`。

## 脚本一览

| 脚本 | 管哪份报告 | 干什么 | 用法 |
| --- | --- | --- | --- |
| `build_report2.py` | 实验2 数据类型、运算符和表达式 | 在模板的四个待填标题后插入正文，代码按 Consolas 10.5 磅排；流程图由 mermaid.ink 渲染后居中插入 | `python build_report2.py <模板.docx> <输出.docx>` |
| `build_report3.py` | 实验3 简单的C程序设计 | 在六个一级标题后插入正文，源码从 `实验3/c-files/` 读 | 同上 |
| `build_report4.py` | 实验4 循环控制 | 取实验3报告的封面，改项目名称、编号、实验时间后重排七节，源码直接读 `实验4/` | `python build_report4.py <模板.docx> <输出.docx>` |
| `build_report5.py` | 实验5 数组 | 取上一份报告的封面，改项目名称、编号、实验时间后重排七节，源码直接读 `实验5/` | `python build_report5.py <模板.docx> <输出.docx>` |
| `build_report6.py` | 实验6 函数 | 取实验5报告的封面，改项目名称、编号、实验时间后重排七节，源码直接读 `实验6/`（8 个源码） | `python build_report6.py <模板.docx> <输出.docx>` |
| `format_report1.py` | 实验1 C语言程序初步 | 把实验1改成实验2的版式（悬挂缩进、代码缩进、插图居中） | 同上 |
| `normalize_indent.py` | 通用，实验1～3都跑过 | 正文左缩进0、首行缩进2字符（21磅）、1.5倍行距；代码保持左缩进42.8磅、单倍行距；正文里的 Consolas 片段改回 Times New Roman 12 磅 | 同上 |
| `align_spacing.py` | 通用 | 设段前段后：实验目的三条各7.8磅，「实验内容和要求」的组标题段前15.6磅、段后7.8磅，其余为0。目的是让三份报告的前十三个段落上下对齐 | 同上 |

## 一份报告的标准流程

1. 在 Word 里把学校发来的「实验N ⋯⋯.doc」另存为 docx，封面、实验目的、实验内容和要求、主要仪器设备先填好，当作模板。
   实际上实验4 起用的模板是**上一份报告的 docx**：仓库里只存 .doc，转成 docx 要靠 Word 另存。
   用脚本转（PowerShell + Word COM）时，保存目标要放在 `C:\temp` 这类纯英文短路径下，
   直接存到 `%TEMP%` 的子目录里会卡住不返回（2026-11-10 实测，换个目录就正常）。
2. 跑 `build_reportN.py`：模板进，正文填好出。
3. 跑 `normalize_indent.py`：缩进与字体对齐。
4. 跑 `align_spacing.py`：段间距对齐。
5. 回 Word 看一眼，另存为 `.doc`，放回 `实验N/实验N 实验报告.doc`。

注意：Word 里正开着目标 `.doc` 时保存会失败，提示文件已在别处打开。先关掉 Word，或者先输出到临时目录再覆盖。

## 版式标准

以2026-10-20定稿的 `实验1/实验1 实验报告.doc`、`实验2/实验2 实验报告.doc` 为准，完整规则在仓库根的 `AGENTS.md` 那张表里。要改版式，先改这两份定稿，再同步脚本里的常量，不要反过来。

## 后续实验怎么开工

实验4、实验5、实验6 都已经有脚本了：`build_report4.py`、`build_report5.py`、`build_report6.py`，模板用上一份报告（脚本会删掉其正文，改封面三项后按新实验内容重排七节），源码直接读 `实验N/` 下的 .c 文件。

实验7 起照它们的样子改三处就行：`EXP6` 指向 `实验N`、`SOURCE` 里的文件名换成新实验的、七节文字内容换成新实验的；模板还是拿上一份报告的 docx（封面字段要记得改实验项目名称、编号与实验时间）。封面是逐段改 run 的：实验项目名称那段改「实验N」里的数字和科目名，编号那段改最后一位，实验时间那段把日期数字改掉（月份没变就不用动）。

## 各实验目录里的东西

| 路径 | 内容 |
| --- | --- |
| `实验N/实验N ⋯⋯.doc` | 学校发来的题目纸，模板来源 |
| `实验N/实验N 实验报告.doc` | 自己交的成品 |
| `实验N/实验N 流程图.md` | 流程图的 mermaid 源码，用 mermaid.live 截图后贴进报告 |
| `实验N/c-files/` | 报告里要贴的源码，实验2、实验3 用这个目录；实验1、实验4 的源码直接放在实验目录里 |
| `实验N/image/` | 运行截图、报错截图；实验4 的 `fig1`～`fig3` 是「分析与预期结果.jpg」里红笔批注的抠图，只作中间产物，报告里已改成文字转录 |
| `给同学的实验-2026年实验报告/` | 学校统一格式模板与实验1～6的空白报告，改模板时对照用 |
