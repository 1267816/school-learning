# 实验3 流程图集合

截图用 <https://mermaid.live/>：把下面的代码整段粘进左侧编辑器，右侧出图后截图。
报告里已经放了同款渲染图，需要换成自己的截图时，删掉对应位置的原图再粘贴。

## 1. 实验3-1 读字符与两种输出

```mermaid
flowchart TD
A([开始]) --> B[/读入第一个字符 c1/]
B --> C[/再读一个字符，吃掉回车/]
C --> D[/读入第二个字符 c2/]
D --> E[/用 printf 输出 c1 与 c2/]
E --> F[/用 putchar 输出 c1 与 c2/]
F --> G([结束])
```

## 2. 实验3-2.1 判断 x 是否为 0

```mermaid
flowchart TD
A([开始]) --> B["x = 3"]
B --> C{"x == 0 ？"}
C -- 是 --> D[/输出 x/]
C -- 否 --> E[/输出 x + 1/]
D --> F([结束])
E --> F
```

## 3. 实验3-2.2 奇数求平方

```mermaid
flowchart TD
A([开始]) --> B[/输入整数 a/]
B --> C{"a % 2 != 0 ？"}
C -- 是 --> D["b = a * a"]
D --> E[/输出 b/]
C -- 否 --> F([结束])
E --> F
```

## 4. 实验3-3 大写字母转小写

```mermaid
flowchart TD
A([开始]) --> B[/输入字符 x/]
B --> C{"x 在大写字母区间？"}
C -- 是 --> D["x = x - 'A' + 'a'；y = x"]
C -- 否 --> E["y = x"]
D --> F[/输出 y/]
E --> F
F --> G([结束])
```

## 5. 实验3-4 成绩分级（if 版）

```mermaid
flowchart TD
A([开始]) --> B[/输入成绩 score/]
B --> C{"score 小于0 或 大于100 ？"}
C -- 是 --> D[/输出输入数据错/]
C -- 否 --> E{"score >= 90 ？"}
E -- 是 --> F[/输出 A/]
E -- 否 --> G{"score >= 80 ？"}
G -- 是 --> H[/输出 B/]
G -- 否 --> I{"score >= 70 ？"}
I -- 是 --> J[/输出 C/]
I -- 否 --> K{"score >= 60 ？"}
K -- 是 --> L[/输出 D/]
K -- 否 --> M[/输出 E/]
F --> N([结束])
H --> N
J --> N
L --> N
M --> N
D --> N
```

## 6. 实验3-4 成绩分级（switch 版）

```mermaid
flowchart TD
A([开始]) --> B[/输入成绩 score/]
B --> C["tens = score / 10"]
C --> D{"tens 的值"}
D -- 10 --> E{"score == 100 ？"}
E -- 是 --> F[/输出 A/]
E -- 否 --> G[/输出输入数据错/]
D -- 9 --> H[/输出 A/]
D -- 8 --> I[/输出 B/]
D -- 7 --> J[/输出 C/]
D -- 6 --> K[/输出 D/]
D -- 1 到 5、0 --> L{"score >= 0 ？"}
L -- 是 --> M[/输出 E/]
L -- 否 --> N[/输出输入数据错/]
D -- 其他 --> O[/输出输入数据错/]
F --> P([结束])
G --> P
H --> P
I --> P
J --> P
K --> P
M --> P
N --> P
O --> P
```
