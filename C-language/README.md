# C-language

C语言课的资料与代码。

| 目录 | 内容 |
| --- | --- |
| `docs/` | 课件、实验指导 |
| `notes/` | 笔记 |
| `c-files/experiment/` | 实验代码，`experiment_1-1.c` 表示第1次实验第1题 |
| `experiment-report/` | 实验报告与流程图源码，按实验号分成 `实验1/`、`实验2/`，`tools/` 是报告生成脚本 |

编译产物（`.exe`）不入库，克隆后需要自己用Dev-C++编译。

## 源码编码提醒

`.c`文件是教室电脑上Dev-C++ 5.11保存的 **ANSI（GBK）** 编码。用VS Code打开时要把编码切成GBK（右下角编码 → `Reopen with Encoding` → GBK）才能正常显示中文注释，**不要另存为UTF-8**，否则教室电脑上的Dev-C++打开又会乱码。详细说明见仓库根目录README的“源码编码”一节。
