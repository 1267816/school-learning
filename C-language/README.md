编译产物（`.exe`）不入库，克隆后需要自己用 Dev-C++ 编译。

## 源码编码提醒

`.c` 文件是教室电脑上 Dev-C++ 5.11 保存的 **ANSI（GBK）** 编码。用 VS Code 打开时要把编码
切成 GBK（右下角编码 → `Reopen with Encoding` → GBK）才能正常显示中文注释，**不要另存为
UTF-8**，否则教室电脑上的 Dev-C++ 打开又会乱码。详细说明见仓库根目录 README 的
"源码编码"一节。
